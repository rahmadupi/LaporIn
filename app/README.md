# LaporIn

LaporIn adalah aplikasi pelaporan warga berbasis mobile untuk membantu masyarakat melaporkan kerusakan fasilitas umum, kondisi lingkungan berbahaya, dan masalah infrastruktur publik.

## SDG Alignment
LaporIn mendukung SDG 11 melalui pelaporan fasilitas publik dan ruang kota yang lebih aman. Sistem pelacakan laporan juga mendukung SDG 16 karena membantu transparansi dan akuntabilitas layanan publik.

## Citizen Features
- Firebase Authentication
- Create Report
- Read Report History
- Update Pending Report
- Soft Delete Report
- Upload Photo to Firebase Storage
- Select Location with Google Maps
- Reverse Geocoding
- Watch Zones
- Push Notification
- Notification Center

## Tech Stack
- Flutter
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
- Google Maps SDK
- Geocoding API

## Firebase Setup
1. Enable Email/Password Authentication.
2. Create Firestore Database.
3. Enable Firebase Storage.
4. Enable Cloud Messaging.
5. Deploy Firestore and Storage rules.

## Demo Flow
1. Register/Login as Citizen.
2. Create report with photo and location.
3. View report history.
4. Edit pending report.
5. Soft delete report.
6. Open map.
7. Create Watch Zone.
8. Test push notification.
